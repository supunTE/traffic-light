# 1.0.0 — 27 August 2026

A coloured light per Claude Code session, a chime on the changes that matter,
and a push to your phone — so you can leave the desk and be pulled back only
when something actually needs you.

**Five signals, one glance.** Every session is Broken, Asking, Done, Working or
Idle. The menu bar shows the most urgent one across all of them; the floating
bar shows one bulb per session, lies horizontally or vertically, and expands on
hover to name them. The two signals that mean *act now* differ in shape as well
as colour.

**A chime on changes, never on states.** A session sitting in Asking rings once
rather than nagging. Several finishing together ring once, for the most urgent.

**Push to your phone through ntfy.** No account and no pairing: a QR subscribes
an Android phone in one scan, and the server and topic are there in plain text
for an iPhone. The title is the session, the icon is the state, and sessions
that stop at the same moment arrive as one notification rather than one buzz and
a silence. Message text is never sent unless you ask for it.

**Quiet hours and per-project rules.** Windows of the week that are Quiet or Off
duty, a snooze in the menu, and a level per project so one repository can go
silent without touching the rest. Quiet still delivers to the phone — it just
does not buzz.

**A Settings window** for all of it, with no Save button: the daemon re-reads
within a second, so a chime you pick is a chime you can hear. Every control
carries a name for VoiceOver, sliders read out in the units shown beside them,
and the day picker speaks full weekday names.

**A session can call for help.** When Claude gets properly stuck it can run
`traffic-light broken "<reason>"` — a Distress Call — and the light goes red
with the reason in plain English. It outranks whatever the session was doing,
because Claude asking for help is stronger evidence than anything the daemon
infers on its own.

**It works from a terminal too.** `traffic-light status` prints the same
picture the menu bar is showing. `traffic-light doctor` checks every part of
the install — daemon, hooks, push, chimes — and names the command that fixes
whichever one is wrong. `traffic-light preview` shows every signal with its
wording and its chime, so you can hear what you are choosing.

**It starts when you log in**, registered through macOS Login Items as the app
itself rather than a nameless background job, and quits from its own menu — it
stays quit until you next log in, rather than reappearing a second later.

**Nothing slow runs inside your session.** A hook stamps its payload, drops one
file and exits. Sound, network and UI all live in a daemon outside Claude's
process tree, where they cannot hang real work.

**The installer says what it will do, and waits.** It prints every file it will
create, the four things it will do, and the two lines it adds to your Claude
Code settings — then stops and asks. `--dry-run` prints the plan and touches
nothing; `--yes` skips the question for CI or a reinstall. With no terminal to
ask on it refuses rather than assuming you meant yes. `uninstall` lists what
goes and what stays, with sizes, and names the two directories that are Claude
Code's to delete rather than ours. `--purge` takes your settings and logs too.

**It keeps its own house.** A session whose process is gone is collected an
hour after its last event, so a restart in progress is never mistaken for a
death. One that is still running but has been silent for eight hours fades to
a half-weight ring and stops driving the menu bar, without being hidden.
`traffic-light cleanup` collects the finished ones immediately when you would
rather not wait, and never touches anything still running.

## Known limits

- **macOS only, and built on your Mac.** Nothing is downloaded, signed by us, or
  notarized. It needs the Swift toolchain from Xcode Command Line Tools.
- **Clicking a session brings Claude to the front but cannot focus that
  session.** No URL scheme Claude Code publishes can; the one that looks like it
  can imports a duplicate instead.
- **Hooks load when a session starts.** After installing, open a new session —
  or restart Claude — before checking `traffic-light doctor`.
- **On the public ntfy.sh the topic name is the whole of the access control.**
  Anyone who knows it can read your notifications, and send their own.
- **The Settings window needs 880pt of width.**
